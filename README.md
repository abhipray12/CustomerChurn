# Churn Prediction on Databricks (Delta Lake Pipeline)

## Overview
An end-to-end churn prediction pipeline built on Databricks Community Edition using Delta Lake, PySpark, and SQL Analytics.

## Stack
- Databricks Community Edition
- PySpark
- Delta Lake
- SQL
- MLlib

## Pipeline Components
1. Data Ingestion
2. ETL & Cleaning
3. Delta Lake Storage
4. SQL-based Analytics
5. Feature Engineering
6. Churn Model Training
7. Prediction Storage

## Structure
See `notebooks/` folder for pipeline stages.


## How to Run
1. Import notebooks to Databricks CE
2. Upload dataset manually
3. Run in order from `01_data_ingestion` → `06_predict_store_churn`
